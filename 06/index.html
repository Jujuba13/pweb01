Atividade 06 — Trabalhando com div e span

A tag div é utilizada para agrupar elementos e organizar diferentes áreas de uma página, como menu, conteúdo e rodapé.

A tag span destaca pequenos trechos dentro de um texto sem criar uma nova seção. Nesta página, as duas tags foram utilizadas junto com CSS para construir e personalizar o layout.

O menu representa a parte superior, esta área contém o conteúdo principal e o rodapé encerra a página com as informações finais.
